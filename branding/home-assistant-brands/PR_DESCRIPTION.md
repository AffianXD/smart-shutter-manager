## Add Smart Shutter Manager brand icon

This PR proposes the 256x256 transparent PNG for the custom integration with
domain `smart_shutter`, copied from its existing local brand asset.

The image is square, PNG, and uses the manifest domain as the folder name.
There is no separate logo because the existing mark is square.

This PR is a draft until the Home Assistant Brands maintainers confirm that
new custom integration assets in the legacy `custom_integrations/` directory
are accepted under the current local-branding policy.
